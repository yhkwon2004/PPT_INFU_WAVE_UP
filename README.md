# INFU RETRO 피치덱 — 2026 NEXT WAVE-UP

INFUTECH(팀 WON SHOT)의 발표 자료 **「반려동물 주사약물 투약 관리 AIoT 솔루션」**을 PPT처럼 넘기는 웹페이지로 만든 것입니다. 빌드 없이 `index.html` 하나와 `media/` · `charts/`로 동작합니다(서체는 `index.html` 안에 들어 있습니다).

**웹에서 보기: https://ppt-infu-wave-up.vercel.app** (Vercel, `main`에 푸시하면 자동 배포)
**PowerPoint 파일: [`export/INFU-RETRO_WON-SHOT.pptx`](export/INFU-RETRO_WON-SHOT.pptx)** — 같은 40장 · 발표 노트 · 시연 영상 포함 (https://ppt-infu-wave-up.vercel.app/export/INFU-RETRO_WON-SHOT.pptx)

## 여는 법

- **로컬**: `index.html`을 바로 더블클릭해도 그대로 열립니다(인터넷 없이도 서체 · 그래프 · 영상이 똑같이 나옵니다). 서버로 열려면 이 폴더에서 `python3 -m http.server 8000` → <http://localhost:8000>
- **Vercel**: https://ppt-infu-wave-up.vercel.app — 프로젝트 `ppt-infu-wave-up`이 이 저장소에 연결돼 있어 `main`에 푸시할 때마다 자동 배포됩니다. 빌드가 없는 정적 사이트입니다(`vercel.json`). 파일을 오래 캐시하지 않아, 같은 이름으로 사진 · 그래프를 바꿔도 다음 접속부터 바로 새 파일이 보입니다.
- **GitHub Pages**: 저장소 Settings → Pages → Branch `main` / `/ (root)` → 저장하면 `https://yhkwon2004.github.io/PPT_INFU_WAVE_UP/`에서 열립니다.

**부록 19장**은 본 발표에 쓴 자료의 원문 · 상세입니다: 기술 상세 일곱 장 — 시스템 구성(로드셀 → ADS1232 → ESP32 기기 내 판정 → MQTT 이벤트 → 서버 · 대시보드 · 휴대폰, 1초 측정 · 5초 이내 알림), 하드웨어 · 잡음 설계(PCB 레이아웃 위 ①~⑥ — 로드셀 단자 · 입력 RC 필터 · ADS1232 내장 앰프 + 24-bit ADC · 아날로그 전원 LC 필터 · GND 동박 · 뒷면 ESP32, 같은 번호의 신호 경로 그림), 핵심 알고리즘 · CNN 학습 로그, 판별 파이프라인 ①(기준 유속 자가측정 vₙ = (W_I − W_f)/T → 칼만필터 → r(t) 부호화 → 4×4 패턴, 논문 식 · 그림 그대로), 판별 파이프라인 ②(경량 CNN 층 구조 · 층별 파라미터 80 + 528 + 51 ≈ 660 · TFLite Micro 약 10KB · 선행 Dual-Track 비교), 데이터 구축 · 학습(실측 · 의료 데이터 → 전이학습 → 파인튜닝 → 실측 교차 검증 → 기기 배포, 검증 정확도 최근 6 epoch), 센서 절감 학습(동시 수집 → 상관 분석 r = 0.95 → 보정 튜닝 → 자이로 없는 제품, 상관 산점도 · 학습 장비 신호), 폴대 걸이형 INFU(실물 사진 · 구조 렌더 영상 · 2차 구상도), 논문 전문, ㈜씨엔 공급 약정서 전문, ㈜에스케이엠엔엠 MOU 전문, 현장의 목소리(공개 인터뷰 · 청원 · 보도에 실린 실제 발언 — 야간 임상수의사 · 보호자 청원인 · 수간호사 · 미국 대학 동물병원 ICU 수의테크니션, 진료수의사 근무 어려움 1위 야간 · 휴일 근무 53.4% · 동물병원 서비스 소비자 평가 40개 시장 중 37위), 처방량 · 보도, 업무 부담 완화 근거, 그리고 조사 자료 세 장 — 동물병원 분쟁 상세(한국소비자원 상담 1,941건 → 피해구제 128건 → 해결 32건 · 진료부 확보 여부별 해결률 · 신청 사유 · 소비자원 당부), 수액 카테터 합병증 근거(연구 3편 19.9 ~ 46.6% · 영국 다기관 연구 상세 · 무게 신호로 보는 것과 못 보는 것), 보호자 지출 · 시장 산출식(KB 치료비 2023 → 2025 · 농식품부 2025 양육현황 · TAM / SAM / SOM 계산과 병원당 연 매출), 반려동물 소비 고급화 두 장 — 실제 사진 사례(반려견 오마카세 7코스 5.8만 ~ 7.8만 원 · 서울 반려견 유치원 월 34만 원 · G마켓 개모차 57% · 장례 처리 2년 새 2배, 사진은 보도 · 판매처 이미지)와 지출 추세(펫보험 보유계약 2022 7.2만 → 2025 25.2만 건 · 특급호텔 펫 패키지 1박 63만 원~ · 에르메스 반려견 밥그릇 278만 원 · 연 50만 원 이상 쓰는 고객 +41% · KB 고정 양육비 월 15.4만 → 19.4만 원).

화면 문구는 짧게 두고, 말할 내용은 장마다 **발표 노트**(`N`)에 있습니다. 타이머는 없습니다.

## 조작

| 키 | 동작 |
|---|---|
| `PageDown` `→` `Space` · 클릭/탭 · 휠 · 밀기 | 다음 장 (한 번에 한 장, 요소는 들어설 때 자동으로 나타남) |
| `PageUp` `←` `Backspace` | 이전 |
| 숫자 + `Enter` | 해당 장으로 (예: `16` `Enter`) |
| `O` | 목차 |
| `N` | 발표 노트 |
| `F` · `F5` | 전체 화면 (프레젠터의 슬라이드쇼 버튼) |
| `B` | 화면 가리기 |

**발표는 프레젠터(클리커)의 다음 · 이전만으로 진행됩니다.** 마우스로 눌러야 하는 것이 화면에 없고, 시연 영상은 장에 들어서면 저절로 재생되며 영상 흐름 목록도 따라 움직입니다. 노트북에서 열면 첫 장 위에 안내 창이나 조작 막대가 뜨지 않고, 조작 막대는 마우스를 실제로 움직일 때만 나타납니다(가만히 있는 커서 아래에서 화면이 바뀔 때 브라우저가 보내는 이동 신호는 무시)(연습할 때는 사진 · 문서를 눌러 크게 볼 수 있습니다).

휴대폰에서도 슬라이드 뷰어처럼 16:9 화면 그대로 보여 줍니다 — 세로로 들고 있으면 뷰어가 옆으로 돌아가 화면을 꽉 채우고, 기기를 가로로 돌리면 바로 섭니다. 탭(왼쪽은 이전) · 밀기로 넘기고, 홈 화면에 추가하면 주소창 없이 가로 전체 화면으로 열립니다. 주소에 지금 장이 남습니다(`#mou`, `#sensor` …).
